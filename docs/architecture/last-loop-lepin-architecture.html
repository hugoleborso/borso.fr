Single page application

container-browser

React, Vite, TanStack Query. The public dashboard and the admin screens behind the PIN. Reads and writes through the API.

26 blueprints103 followers

HTTP API

container-aws

Hono on AWS Lambda, Drizzle. Every endpoint, with the admin ones gated by a session row rather than a secret. Its inferred router type is the contract the single page application compiles against.

25 blueprints54 followers

Application database

container-aws

Aurora DSQL, Postgres wire protocol, Drizzle. One schema per stage inside a cluster shared across stages. Holds the runners, the punches, the editions, and the admin credentials and session rows.

Photo bucket

container-aws

Amazon S3 behind its own CloudFront distribution. Holds the runner photos the official uploads. Served through PhotosCdn rather than from the API.

Infrastructure definition

container-build

AWS CDK, PreviewableApp plus PhotosCdn. Composes the shared constructs into this application stack. Build-time only, never reached at runtime.
