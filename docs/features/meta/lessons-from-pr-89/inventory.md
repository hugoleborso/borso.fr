# Friction inventory — PR #89, *The room picks the next song*

Every friction event logged or found while PR #89 was built, and what this
sweep decided about each. The body of [the kaizen pull request](https://github.com/hugoleborso/borso.fr/pulls)
carries the counts; this is the evidence behind them.

Rows 01–49 come from `KAIZEN.md`, the gitignored friction log twelve writers
appended to during the task. Rows 50–54 were found by this sweep itself, four
of them by a gate it had just written, which is the argument for writing the
gate before the entry rather than after.

**Read the writer, not only the line.** Three agents hit the `@borso/pragma`
filter (rows 06, 13, 16) and it turned out to be already fixed on main — worth
verifying rather than assuming. Four hit the Biome instructions (04, 07, 09,
20), which is what promoted a text fix into a gate. Three hit the agent-browser
wedge (24, 28, 34), which is what turned a knowledge note into a change to
`scripts/browser.sh`. One agent hitting a wall is a local problem; four is a
systemic one, and the two deserve different eradications.
