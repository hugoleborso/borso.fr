## Notes

- **01 FAIL.** Every bar should be empty when all values are 0. Instead each member row shows a 2 px dashed tick in the member's colour, at the left of the track. The expected outline is `width: 0%` but keeps its `border-[1.5px] border-dashed` (`EXPECTED_BAR_CLASS` in `apps/pragma/site/src/components/organisms/ConcertFriendsCard.tsx`), so its two side borders still paint. The zoom shows it in `02-all-zero-dashed-tick-zoom.png`. The same tick shows for any member whose expected count is 0 while the scale is above 0. The Tempo row in a stale-cache screenshot during this run showed it at "0 / 0" (measured). That screenshot was replaced, so it is not in the evidence folder. The solid bars and the Sans préf. bar are 0 px and empty.
- **16 FAIL.** The rule makes the mockup the reference for copy. The mockup's venue line reads "Jauge de la salle". The card reuses `sessions.capacity` = "Jauge", which is also the label on `main` (read with `git show origin/main`). Typography differs too, though no rule names it. The counts, header and venue figures use `font-mono`, where the mockup uses Geist sans. At 375 px the wider mono header wraps under "AMIS PAR MEMBRE", where the mockup keeps it on one line. At 1280 px it stays on one line (`06-desktop-1280.png`).
- Row 13, observation only. The subtitle reads "14 nombre d'amis attendus" in French and "14 expected friends count" in English. The subtitle builds this from `sessions.friendsCount` lowercased, the same key as on `main`. The spec asks only that the subtitle keep the count, so the row passes. The phrasing still reads awkwardly.
- State left on the local dev database: four expected counts and fifteen "FanN" registrations on "Le Petit Bain". The temporary member was created and then deleted. The next `pnpm dev` reseeds everything.

## Verdict: FAIL
