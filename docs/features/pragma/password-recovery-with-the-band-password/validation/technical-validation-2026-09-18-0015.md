The race is in the test, not in the diff: `VotePage.tsx` imports `audience.queries`, `Button`, `Card`, `AudienceVoteList`, `SuggestSongField` and `live-concert.core`, none of which appear in `git diff origin/main...HEAD`, and `auth.queries.ts` — the only query file this branch edits — is not in its graph. It is nevertheless a red gate on this branch's own required suite, and this repository's standing rule is that "preexisting is not an excuse", so it is recorded as FAIL rather than waived. The fix belongs in the vote test's flush discipline (one `flushMicrotasks()` is not enough to settle the optimistic retract), not in this feature. Logged to the friction journal.
- **D07 — the 503 edge case has no test.** The spec names it explicitly ("The application was never bootstrapped, so `app_config` holds no row. The endpoint answers 503, as login does."), the controller does implement it (A19), and it is a deterministic non-DOM behaviour, so it belongs to this validator rather than `/visual-validation`.
