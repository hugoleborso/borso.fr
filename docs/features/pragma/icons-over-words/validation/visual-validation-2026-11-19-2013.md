## Notes

- **14, UNVERIFIABLE, needs a product call.** Rule 5 says "name fields and pickers" keep words. It does not say whether that means member pickers only or any picker. The two lineup editors are pickers of instruments. They are the song's Default lineup sheet and the setlist entry's "Lineup tonight" tab. This change made them icon-only. Each instrument toggle used to show its name, and now shows only its glyph, with `aria-label` = `title` = the name. Toggles whose glyph is generic or shared still show their names. Each member row used to show the name beside the mark, and now shows the mark alone. The group stays named "Hugo — Instruments" for screen readers. The task assignee picker (row 13) still shows its words. If "pickers" covers instrument pickers, this row is a FAIL. If it covers name pickers only, it is a PASS. The diff to `InstrumentToggleGroup.tsx` and `LineupMemberRow.tsx` shows the words were removed on purpose.
- **20, UNVERIFIABLE, needs a product call.** Rule 1 says that wherever a member's avatar is shown, the name is not written beside it. Rule 5's exceptions do not list the Members management list. That page still shows "H Hugo", "L Léa" and so on. This may be meant to fall under "name fields and pickers", since each row opens the member's name form. The spec does not say so.
- **18, UNVERIFIABLE.** "former member" shows on takes, the take player and inspiration cards when the author was deleted. The local data has no such item. Making one means authoring content as another member and then deleting that member, on a local database other agents may share. A take also needs an upload, and no bucket runs locally. The diff does not touch `TakeList.tsx`, `TakePlayer.tsx` or `InspirationCard.tsx` (checked with `git diff 2c4b1e983 HEAD`). The label is therefore unchanged in code, but this run did not see it on screen.
- **Observation, not scored.** The coloured instrument chips under each setlist row and concert setlist row come from `LineupSlots.tsx`. Each chip has a `title` but no accessible name, and its glyph is `aria-hidden`. The row button reads "02 Midnight Drive Nova Reef · C" with no instruments. This feature did not change that component (its last commit is #279). It replaced no word, so it falls outside Result 7.
- Hover tooltips were checked through the `title` attribute. Headless Chromium does not paint native tooltips into a screenshot.
- The spec names no dark-mode or reduced-motion behaviour, so neither was checked.
