# Pragma UX audit: verified findings, second pass

## What this file is

The first skeptic worked without the three auditors' findings, because those findings were only recovered from transcripts later. This pass takes the 62 findings in `audit-structure/findings.md` (26), `audit-pwa-touch/findings.md` (15) and `audit-design-system/findings.md` (21), tries to refute each blocker and major and a sample of minors, and merges the result with `skeptic/verified.md`. Duplicates are merged into one row that keeps every id.

**How I checked.** I ran my own instance on port 5181 with the seed data, and drove it with Playwright as an installed phone app at 375x667 (standalone forced, top inset 20), using a copy of the first skeptic's helper (`skeptic-2/lib.mjs`). The probes are `probe-setlist.mjs`, `probe-other.mjs`, `probe-tasks.mjs` and `probe-vote.mjs`, and screenshots are in `skeptic-2/shots/`. Taps went through Playwright's touch emulation, not argent. For every finding I also read the cited code.

**Verdicts.**
- **Confirmed live**: I reproduced it on my instance this session.
- **Confirmed in code**: the code shows it without doubt, but I did not reproduce it on screen. This applies to the offline and service worker findings, which need a production build.
- **Refuted**: I could not reproduce it, the cause given is wrong, or it depends on something the emulator cannot show. Following the brief, a claim I could not reproduce counts as refuted.

## Refuted findings

| Ids | Claim | Why refuted |
| --- | --- | --- |
| audit-structure-1 (as blocker) | The person cannot edit a task without help. | The defect is real (rank 2), but the form can be reached by scrolling, so the person finishes, slowly. Kept as major. |
| audit-structure-14 (Escape part) | Escape leaves the song picker open. | Escape closed it in my run: the native dialog fires `close`, and the picker passes `onClose`. On Android the back gesture uses the same path. The rest of the finding stands (rank 16). |
| audit-structure-25, audit-pwa-touch-10, audit-design-system-19, first-pass row 17 | Header controls sit under the status bar. | The overlap exists only because the emulator forces a top inset. `index.html:13` sets `apple-mobile-web-app-status-bar-style` to `default`, so an installed iOS app starts below the status bar. All three auditors say so themselves. It becomes a real bug only if the style changes to `black-translucent`. |
| audit-pwa-touch-8 | Save buttons and fields sit under the keyboard. | Every number rests on a keyboard height the auditor assumed (260 px and 336 px); no keyboard is drawn in the emulator. Unproven, so refuted under the brief's rule. Worth one check on a real phone, mainly for the transition dialog's Save at y=437. |
| audit-structure-24 (as a defect list) | Dialogs double scroll. | The auditor's own conclusion, which I agree with: no dialog has two live scroll areas, because the page behind is locked (`tokens.css`). The real multi-scroll cases are already ranks 14 and 27. Same as first-pass row 16 (S-lineup, S-picker). |
| T-notes "garbled text" | The note became garbled text. | Refuted in the first pass after 8 runs; the touch auditor also withdrew it as a test artefact. The real defect is rank 7. |

## Not re-tested

These came from one auditor, I did not reproduce them, and they are minor or low priority. Under the brief's rule they do not count as confirmed.

- **audit-pwa-touch-12, overshoot part**: a held drag overshot to position 13 with auto-scroll. The structure auditor's real touch drag moved a song from 1 to 3 without trouble.
- **audit-design-system-7**: one song title drawn 8 ways. Consistent with rank 32, not re-measured.
- **audit-design-system-8, -11, -12**: five "selected" looks, four heading styles, card corner drift and cards inside cards.
- **audit-design-system-18**: dark mode gaps (27 raw colours, status chips with no dark value).
- **audit-design-system-20**: the sticky save bar is only as wide as the card and covers "Origine". A sticky bar covering the field under it while scrolling is expected; whether it hides a field at rest was not checked.
- **S-bars** (row 38) and **T-createSession** focus, which rank 23 now covers in general.
