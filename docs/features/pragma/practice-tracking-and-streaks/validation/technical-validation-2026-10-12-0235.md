## Notes

No FAIL or UNVERIFIABLE rows. These observations do not change the verdict:

- **Plan deviation, matrix writes.** The plan's *score change moves readiness* row said the existing mastery override mutation would also invalidate `['studies', 'overview']`, or patch it if it carried `onMutate` (it does: `site/src/lib/queries/mastery.queries.ts:38,68`). Neither happened. The Studies tab uses its own `useStepSongScore`, which invalidates `overview`, `historyOf` and `overridesOf`. The spec's Happy path 3 goes through the Studies tab stepper, which does refresh, so no spec row fails.
