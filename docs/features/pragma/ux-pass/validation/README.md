# UX pass — visual evidence

Screenshots taken against the preview environment this branch's pull request
deploys, at the two widths the repository holds every page to: a 1280 px
desktop and a 375 px phone.

Each file is named `<width>-<surface>.png`.

| Surface | What it shows |
| --- | --- |
| `setlist` | The transition strip on every gap: who can carry it, the risky flag, the note stored on the pair. |
| `song-picker` | The add-a-song sheet, including the offer to create the title being typed. |
| `lineup-editor` | One member holding two instruments at once. |
| `song` | The song page with its structure, gimmick and free notes. |
| `catalog` | The catalog, with the create path visible on a phone. |
| `instruments` | The instrument families the transition rule reads. |
| `scene` | The stage view, structure notes above the chart. |
