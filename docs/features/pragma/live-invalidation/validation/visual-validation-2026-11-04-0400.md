- **19 UNVERIFIABLE.** No API route this run could call sends `all`. A client frame with `all` changed nothing (row 07), as the spec wants. So the "every query" branch had no trigger.
- **21 UNVERIFIABLE.** A 410 needs a connection API Gateway still lists but that is gone. No browser action produces one on demand, and `scripts/db-read.sh` reads production, not this preview's schema.
- **22 UNVERIFIABLE.** No send failed or ran slow. Sentry was not read.
- **24 UNVERIFIABLE.** Row deletion on `$disconnect` needs the preview's `realtime_connection` table, as in row 21.
- **25 UNVERIFIABLE.** A WebSocket client never sees the status a `$default` integration returns.
- **27 UNVERIFIABLE.** `apps/pragma/api/src/main.dev.ts` line 47 sets `WEBSOCKET_CLIENT_URL` unconditionally, so neither `pnpm dev` nor the preview runs with no socket URL. Row 28 covers the client half by answering the ticket with no URL.
- **Observation on rows 15 and 18, not a FAIL.** A message makes every open tab refetch at the same instant. After one `written:["me"]`, 5 of lea's 11 refetches answered `503 {"message":"Service Unavailable"}` and succeeded on the retry 1.2 s later, so the screen recovered with no visible error. A burst of 18 parallel plain GETs from one tab reproduced it (3 of 18 answered 503), so the limit is the preview API's capacity, which this fan-out reaches more often. Measured, on the preview only; prod capacity was not checked.
- **Observation on row 29.** The Order page refetches `entries` on every mount whatever its age (control: 3 s). The spec says nothing about this.
- **Offline emulation is not a phone losing its socket.** `Network.emulateNetworkConditions` offline left lea's open socket untouched, so the run used hidden plus frozen (row 06) instead.
- The pixel-content check returned `[]` after every screenshot. No console errors in hugo's, lea's or marc's tab.
- Preview data changed by this run: setlist `2756b530…` order (it ends Midnight Drive, Afterglow, Lightning, Runaway Sun, Last Call, Slow Burn), Slow Burn's energy (3 to 4), marc's phone (`+33600000007`).
